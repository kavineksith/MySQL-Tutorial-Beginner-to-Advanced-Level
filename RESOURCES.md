## The Single Most Important Next Step

### 📕 Read the Official MySQL Documentation

After finishing this course, the single most valuable thing you can do is
bookmark and regularly consult the [MySQL Reference Manual](https://dev.mysql.com/doc/refman/8.0/en/).
It is the canonical source for every MySQL feature, function, and behavior.

> **Pro tip**: When you encounter a SQL function or keyword you don't
> fully understand, look it up in the official docs. The explanations are
> thorough and include examples.

Key sections to bookmark:
- [SQL Statement Syntax](https://dev.mysql.com/doc/refman/8.0/en/sql-statements.html)
- [Functions and Operators](https://dev.mysql.com/doc/refman/8.0/en/functions.html)
- [Data Types](https://dev.mysql.com/doc/refman/8.0/en/data-types.html)
- [Joins](https://dev.mysql.com/doc/refman/8.0/en/join.html)
- [Window Functions](https://dev.mysql.com/doc/refman/8.0/en/window-functions.html)
- [EXPLAIN Output Format](https://dev.mysql.com/doc/refman/8.0/en/explain-output.html)

### SQL Standard

The SQL standard is ISO/IEC 9075. The latest version is **SQL:2023**.
The standard is not freely available, but you can read about the changes
in each version:

- [SQL:2023 — what's new](https://modern-sql.com/blog/2023-10/sql-2023)
- [SQL:2016 — what's new](https://modern-sql.com/blog/2019-02/sql-2016)
- [modern-sql.com](https://modern-sql.com/) — tracks standard SQL features across databases

## Advanced Topics to Study Next

After finishing this course, these topics will deepen your expertise:

### 1. Query Optimization

- Reading `EXPLAIN` output in depth
- Index merge optimization
- Hash join vs. nested loop join
- Materialization and subquery optimization
- The optimizer trace

📖 [Use The Index, Luke!](https://use-the-index-luke.com/) — the best free
resource on indexing.

### 2. Database Design & Normalization

- 1NF, 2NF, 3NF, BCNF, 4NF, 5NF
- Denormalization: when and why
- Star schema and snowflake schema (for data warehousing)
- Slowly Changing Dimensions (SCD)
- Entity-Relationship modeling

📖 *Database Design for Mere Mortals* by Michael J. Hernandez

### 3. Transaction Isolation Levels

- Read Uncommitted, Read Committed, Repeatable Read, Serializable
- MVCC (Multi-Version Concurrency Control)
- Phantom reads, dirty reads, non-repeatable reads
- How each database engine implements isolation

📖 [MySQL InnoDB Locking](https://dev.mysql.com/doc/refman/8.0/en/innodb-locking.html)

### 4. Replication & High Availability

- Master-slave replication
- Group replication
- Galera cluster
- Read replicas vs. write replicas
- Sharding strategies

📖 [MySQL Replication](https://dev.mysql.com/doc/refman/8.0/en/replication.html)

### 5. Stored Procedures & Functions (Advanced)

- Dynamic SQL with PREPARE/EXECUTE
- Cursor-based processing
- Error handling with DECLARE HANDLER
- Stored functions vs. procedures
- Performance considerations

📖 [MySQL Stored Programs](https://dev.mysql.com/doc/refman/8.0/en/stored-programs-views.html)

### 6. Window Functions (Advanced)

- Frame specifications (ROWS vs. RANGE)
- Running totals and moving averages
- Gap and island problems
- FIRST_VALUE, LAST_VALUE, NTH_VALUE
- Percent rank and cumulative distribution

📖 [MySQL Window Functions](https://dev.mysql.com/doc/refman/8.0/en/window-functions.html)

### 7. JSON in MySQL (Advanced)

- JSON_TABLE for flattening JSON into rows
- JSON path expressions
- Generating JSON from SQL (JSON_OBJECT, JSON_ARRAY)
- Indexing JSON columns with generated columns
- JSON schema validation

📖 [MySQL JSON Functions](https://dev.mysql.com/doc/refman/8.0/en/json-functions.html)

### 8. Full-Text Search

- Natural language mode vs. boolean mode
- InnoDB FULLTEXT vs. MyISAM FULLTEXT
- Relevance scoring
- ngram parser for CJK languages
- Combining FULLTEXT with other search tools (Elasticsearch, Meilisearch)

📖 [MySQL Full-Text Search](https://dev.mysql.com/doc/refman/8.0/en/fulltext-search.html)

### 9. Other Database Engines

- **PostgreSQL**: richer type system, advanced indexing (GIN, GiST), PL/pgSQL
- **SQLite**: embedded, serverless — perfect for testing and small apps
- **ClickHouse**: column-oriented OLAP database
- **DuckDB**: in-process analytics database
- **Trino/Presto**: distributed SQL query engine

### 10. NoSQL and Polyglot Persistence

- When to use NoSQL vs. SQL
- MongoDB (document), Redis (key-value), Cassandra (wide-column), Neo4j (graph)
- CQRS and event sourcing
- Using SQL and NoSQL together
